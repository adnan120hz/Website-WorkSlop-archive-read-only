# Website WorkSlop (archive, read only)

Static snapshot of the official WorkSlop website, archived for later
deployment to Vercel.

- `index.html` — the complete site as one self-contained file
  (styles, scripts and images inlined; no build step).

## Deploy to Vercel

Import this repository in Vercel (or run `vercel` in this folder).
No framework preset, no build command, no output-directory override
needed — the repo root is served as-is.

WorkSlop Desktop: https://github.com/adnan120hz/WorkSlop-Desktop-Version
